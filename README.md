# ブロックフォール 3D

Three.js で作った 3D 落ち物ブロックパズルゲームです。ブラウザだけで遊べます。

## 遊ぶ

👉 https://picopico-bdash.github.io/blockfall-3d/

## 画質設定

タイトル画面の「画質」ボタンで **自動 / 高画質 / 軽量** を切り替えられます。
「自動」では次の環境で軽量モードになります。

- スマートフォン・タブレット
- ブラウザのハードウェアアクセラレーション（グラフィックカード）が無効な PC

軽量モードでは次のように描画負荷を下げます（ゲーム内容は変わりません）。

- 透過ガラス・ブルーム（発光のにじみ）・影をやめ、Blender でレンダリングしたガラスの質感画像 `matcap_glass.jpg` で描画
- ボムの光はブルームの代わりに軽い発光スプライトで表現
- スマホは描画解像度を最大 1.5 倍に抑え、フレーム時間に合わせて自動で下げる（動的解像度）
- 描画は最大 60 fps（120Hz 画面では 1 フレームおきに描画、ハードウェアアクセラレーションなしの PC は 30 fps）

どの画質でも、効果音は Web Audio で再生し（スマホで要素生成による引っかかりが出ないように）、タイトル画面では 3D の描画を止めます。

### 重いときの調べ方

URL の末尾に `?debug=1` を付けて開くと（例: https://picopico-bdash.github.io/blockfall-3d/?debug=1 ）、
画面左下に fps・フレーム時間・描画解像度・draw call 数が表示されます。

## ローカルで動かす

`index.html` をブラウザで開くか、簡易サーバーで配信してください。

```bash
npx serve .
```
